# 🍸 Alcohol Quiz (お酒の達人クイズ)

カクテルのレシピとお酒の銘柄分類を楽しく学べる、Webベースの4択クイズアプリケーションです。
全100問の豊富なデータから、ランダムに問題が生成されます。


## ✨ 主な機能

- **2つのクイズモード**:
  - **カクテル構成モード**: カクテル名から「ベース」または「割り材」を当てる。1つのデータから出題パターンがランダムに変わります。
  - **お酒の種類モード**: 有名な銘柄名（例：タンカレー、山崎）から、そのお酒の分類を当てる。
- **問題数のカスタマイズ**: 学習スタイルに合わせて、10問〜50問まで選択可能。
- **ノンストップ回答ロジック**: 選択肢をクリックすると即座に判定し、0.6秒後に自動で次へ遷移する快適な操作性。
- **詳細な結果レビュー**: 全問回答後、正誤一覧と「自分の回答」「正解」を比較できる復習機能。
- **レスポンシブ対応**: Bootstrap 5を採用し、PCでもスマートフォンでも快適にプレイ可能。

## 🛠 使用技術

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **UI Framework**: Bootstrap 5
- **Design Tool**: Figma (UI設計に使用)

## 💡 こだわったポイント（技術的工夫）

- **動的な問題生成**: 
  JavaScriptの`Math.random()`を活用し、1つのカクテルデータから「ベース」を隠すか「割り材」を隠すかを動的に判定しています。これにより、同じデータでも飽きずに学習できる仕組みを作りました。
- **ダミー選択肢の自動抽出**: 
  4択のハズレ選択肢は、全データの中からランダムに抽出されるようアルゴリズムを組みました。
- **UI/UXの向上**: 
  夜のバーをイメージしたダークテーマを採用。また、クイズのテンポを損なわないよう、回答後の「次へ」ボタンを排除し、自動遷移するように実装しました。
